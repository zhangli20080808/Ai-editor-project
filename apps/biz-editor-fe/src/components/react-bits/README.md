# React Bits components

These components are adapted from the TypeScript + CSS variants in
[React Bits](https://github.com/DavidHDev/react-bits), licensed under MIT.

- `Aurora`: adapted for reduced-motion, stable WebGL cleanup, and local color tokens.
- `BlurText`: adapted for semantic `h1` output, reduced-motion, and strict TypeScript.
- `SpotlightCard`: styled by the homepage card system while preserving the original pointer behavior.
