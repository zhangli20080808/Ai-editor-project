# AI Editor 产品演示视频设计规范

## Site Summary

- Site: 新潮设计 AI Editor，一套面向运营人员的 H5 营销页面生成、编辑、检查与发布平台。
- Colors: 深海军蓝 `#070F1C` / `#111827` 作为舞台背景，AI 橙 `#FF5805` 作为关键动作，品牌蓝 `#2F6BFF` 作为辅助强调，白色和浅灰用于信息层级。
- Fonts: 中文采用 `PingFang SC`、`Noto Sans SC`，数字与英文采用 `Inter`。标题使用 700-800 字重，正文使用 400-500 字重。
- Sections: 首页 AI Hero、AI Agent 需求表单、候选草稿、编辑器画布、组件文案助手、页面体检、发布 H5。
- Headings: “一句话，生成你的营销页面”“让页面更清楚，也更会转化”。
- CTAs: “用 AI 创建页面”“生成页面草稿”“应用到画布”“生成 3 个候选”“开始页面体检”“保存”“发布”。
- Key assets: `assets/01-home.png` 至 `assets/08-published-h5.png`，均来自本地真实产品页面；首页补充素材位于 `capture/`。
- Vibe: 专业、克制、偏产品发布会。避免普通录屏感，以大字号结论、真实界面卡片、局部推拉和步骤编号建立节奏。

## Visual System

- 画布为 1920x1080，24fps，目标时长约 150 秒。
- 背景使用深蓝径向渐变、细网格和低透明度橙蓝光晕，保持与首页氛围一致。
- 产品截图置于 16:9 圆角玻璃卡片内，使用轻微透视、阴影和 1px 白色描边。
- 每个章节左上角显示 `01-07` 编号、短标题和一句结论；右下角保留细线式进度条。
- 截图只做平移、缩放和裁切，不使用会降低 UI 可读性的滤镜。
- 重点区域用橙色描边框、柔光和短标签标注；每次只强调一个关键动作。
- 转场采用 10-14 帧的遮罩推入或交叉淡化，场景内部以 0.6-1.0 秒缓动进入。

## Motion Rules

- 所有 GSAP 时间线必须暂停并注册到 `window.__timelines`。
- 动画只使用固定参数，不使用随机值、无限循环或依赖网络的资源。
- 大标题进入：透明度 0 到 1，Y 方向 36px 到 0，`power3.out`。
- 截图进入：透明度 0 到 1，缩放 1.04 到 1，`power2.out`。
- 重点框：缩放 0.96 到 1、透明度 0 到 1，不做持续闪烁。
- 结尾保持至少 3 秒静止，方便观看项目名称和完整链路。

## Audio And Captions

- 首选 Kokoro 中文女声 `zf_xiaobei`；本机模型下载超时后，成片使用 macOS `Tingting` 中文女声生成，语速 190。
- 口播原文保存在 `narration.txt`，字幕基于实际转写结果生成。
- 背景音乐首版不添加，确保口播清楚；后续可在不改变时间线的情况下增加轻量电子氛围音乐。
